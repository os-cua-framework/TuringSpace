# Open Images V7 spatial scene pack

A subset of Open Images V7 validation photographs with multiple boxed objects, explicit occlusion, and non-attribute visual relationships.

## Privacy and scene filter

Selection rejects any image with a bounding-box class `Person`, `Man`, `Woman`, `Boy`, `Girl`, any `Human *` class, or `Vehicle registration plate`.
